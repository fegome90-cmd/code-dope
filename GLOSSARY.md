# Glosario

- **Catálogo:** operaciones que el consumidor habilita de forma explícita.
- **Programa guest:** JavaScript suministrado para ejecutar dentro de QuickJS-WASM; llama sólo herramientas host habilitadas por la policy.
- **Plan declarativo:** propuesta histórica de una lista de pasos y argumentos; no es el contrato del ejecutor actual.
- **Recibo:** resultado por paso con estado y procedencia. No prueba por sí solo que todo el plan pasó.
- **Adaptador:** capa opt-in que expone el núcleo a un host, por ejemplo vía MCP.
- **Llamada nativa:** invocación observada en el host objetivo. Una prueba local no la sustituye.

Estas definiciones describen el candidato de Fase 3 y distinguen las propuestas históricas; no declaran estable la API.
